구간을 추가하거나 선택하세요.

방향·열 번호는 아래 구간 표에서 설정합니다. 수정한 구간은 지도 생성 · 저장을 눌러 적용합니다.

초기값은 전체 영상 · 1열 · 가는 방향입니다. 회전·왕복·다른 열 촬영이 포함된 영상은 구간을 나누세요. 프레임 번호는 원본 영상 기준이며, 지도만 다시 만들 때 모델 추론은 반복하지 않습니다.

1열 75칸 + 2열 80칸 = 기본 155칸입니다. 열 방향·크기·패널 간격에서 벗어난 관측은 제외합니다. 빈 위치는 회색 빗금의 ‘미탐지’이며 정상·오염 판정이나 이미지를 만들지 않습니다. 아래 위치 이동 값은 실제 크기와 별개로, 기본 0을 사용합니다.

띠는 화면 높이의 비율입니다. 패널이 하단에 충분히 보이지 않으면 띠를 넓혀 조정할 수 있습니다. 줄·칸 번호는 지정한 방향만 반영하며 자동으로 뒤집지 않습니다.

영상 분석을 완료하면 전체 구간 기준의 초기 지도를 생성합니다.

실측 좌표가 아닌 열·줄·칸 순번 지도입니다. 파란 점은 왕복 관측을 뜻합니다. 최종 판정은 트랙별 횟수 합산이며 동률은 오염입니다.
